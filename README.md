# CPP06 疑問メモ

## [ex00] 静的メソッドだけのクラスって意味ある？ 関数でよくない？
- C++ は普通の関数や `namespace` で十分なことが多い（Java は関数をクラスに入れる必要があるから使われる）
- クラスにするメリット：補助関数を private で隠せる / 1つの機能としてまとまる
- canonical form の4つは宣言しないと自動生成される → private で宣言してインスタンス化を禁止している

## [ex00] inf / nan ってなに？
- 浮動小数点数（float / double）だけが持つ特別な値。int などの整数型には存在しない
- `inf`（infinity）：無限大。範囲を超えた値や `1.0 / 0.0` の結果。`+inf` / `-inf` がある
- `nan`（Not a Number）：数として意味がない値。`0.0 / 0.0` や `sqrt(-1)` の結果
- `nan` は自分自身とも等しくならない（`nan == nan` は false）→ 判定は `std::isnan()` を使う
- `inf` の判定は `std::isinf()`
- 指数部のビットが全部 1 のとき特別扱いされる：仮数部が 0 なら `inf`、0 以外なら `nan`
- リテラル表記：double は `inf` `-inf` `+inf` `nan`、float は末尾に f を付けて `inff` `-inff` `+inff` `nanf`
- char / int には変換できないので `impossible` と出力する

## [ex00] キャストの種類
| キャスト | 用途 | チェックのタイミング |
|---|---|---|
| `static_cast<T>(x)` | 普通の型変換（double → int、基底 → 派生ポインタ など） | コンパイル時 |
| `dynamic_cast<T>(x)` | ポリモーフィックなクラスの安全なダウンキャスト。失敗するとポインタなら `NULL`、参照なら `std::bad_cast` を投げる | 実行時 |
| `const_cast<T>(x)` | `const` を外す・付ける。型そのものは変えない | コンパイル時 |
| `reinterpret_cast<T>(x)` | ビット列をそのまま別の型として解釈（ポインタ ↔ 整数、無関係なポインタ同士） | なし |
| `(T)x`（C スタイル） | 上の4つを順に試して通るものを使う。どのキャストになったか分かりにくいので C++ では非推奨 | - |

- ex00 は `static_cast`、ex01 は `reinterpret_cast`（ポインタ ↔ `uintptr_t`）、ex02 は `dynamic_cast` を使う
- `dynamic_cast` を使うには、基底クラスに仮想関数（virtual デストラクタなど）が必要

## [ex00] strtod の仕様
- 読めるところまで読んで double を返し、読み終わった位置を `endptr` に返す。末尾の `f` は読まずに `endptr` に残る
  - `"4.2f"` → 4.2、endptr は `"f"` / `"nanf"` `"inff"` も同様に endptr は `"f"`
- 1文字も読めなかったときは `endptr == str` になる（`"."` `"e5"` `"abc"` など）
- `e` / `inf` / `nan` / `5.` / `.5` は問題なく読める
- strtod は通すが C++ リテラルではないもの → 自分で弾く

| 入力 | strtod の結果 | 理由 |
|---|---|---|
| `"  42"` | 42 | 先頭の空白を読み飛ばす |
| `"INF"`, `"Infinity"`, `"NaN"` | inf / nan | 大文字小文字を区別しない。`infinity` も読む |
| `"nan(123)"` | nan | この書式も受け入れる |
| `"0x1p3"` | 8 | 16進数の浮動小数点も読む |
| `"0x2A"` | 42 | C++でも int リテラルとしては正しいが、strtod は double として読む |
| `"042"` | 42 | C++では8進数なので 34 になる。strtod は 10進数として読む |
| `"1e999"` | HUGE_VAL | オーバーフロー。`errno == ERANGE` で検出する |

- `0x` と `042` は課題の範囲外として扱わないのが一般的。先頭の空白と大文字の `INF` は弾くかどうか決めておく

## [ex00] リテラルのサフィックス
- 浮動小数点：`f` `F`（float）、`l` `L`（long double）のどれか1つだけ。重ねられない
- 整数：`u` `l` `ul` `ll` など。`f` は付けられない
- `42f` `42FL` `4.2fl` は C++ に存在しない → エラー
